Trapdoor Chapter 10

Signatures from the blender

One secret per bit

This is Leslie Lamport's signature from 1979. For every bit, the signer picks two random secrets and publishes only their fingerprints. To sign, reveal the secret that matches each bit. A checker fingerprints what you revealed and compares.

Making a fingerprint is quick. Finding a secret that matches one is not, so only the signer could have revealed them.

Only once

Sign two different messages and some columns have both secrets public. Mix and match them, and you can sign messages the owner never saw. Each key is good for one signature.

Many keys, one fingerprint

Ralph Merkle's fix, also from 1979: make many one-time keys, fingerprint them in pairs, then fingerprint those in pairs, up to a single root. Publish only the root. This is a .

A Merkle tree fingerprints data in pairs, level by level, until one fingerprint remains. Changing anything at the bottom changes the root, so the root vouches for everything beneath it. Git and Bitcoin use the same trick.

Merkle tree on Wikipedia

The modern version

In August 2024 NIST standardized SLH-DSA, a descendant of these trees. It trusts nothing but the hash: if fingerprints stay hard to reverse, its signatures stay safe.

A plain Merkle tree forces the signer to remember which one-time keys are used up; reusing one leaks it. A stateless scheme needs no such memory. SLH-DSA picks keys from a giant tree pseudo-randomly, using keys that tolerate a few reuses.

SPHINCS+, the basis of SLH-DSA, on Wikipedia

The price is size. Its public key is 32 bytes, but its smallest signature is 7,856 bytes, over a hundred times an Ed25519 signature.

Hiding a message in mistakes

An older idea, from Robert McEliece in 1978. Take an and disguise it so it looks random. To send a message, encode it and flip some bits on purpose. Only the key holder knows the undisguised code, so only they can repair the errors.

An error-correcting code adds careful redundancy to data so that a few flipped bits can be found and fixed. It is why a scratched disc still plays and why QR codes survive smudges.

Error correction code on Wikipedia

The basic design has survived nearly fifty years of attacks. The catch: its modern form, Classic McEliece, has public keys of 261,120 bytes at the smallest setting.
