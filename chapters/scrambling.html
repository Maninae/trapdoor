The blender

Everything is bits

A computer stores each letter as a : eight bits, each a 0 or a 1. Capital S is 01010011.

A bit is a single 0 or 1. A byte is 8 bits, enough for 256 different values. In the common ASCII code, capital S is number 83, which is 01010011 in binary.

ASCII on Wikipedia

To scramble, line a random key up under the message and apply to each column. The answer is 1 when the two bits differ and 0 when they match. Do it again with the same key and the message comes back.

XOR means "exclusive or": one or the other, but not both. 0 XOR 0 = 0, 0 XOR 1 = 1, 1 XOR 0 = 1, and 1 XOR 1 = 0. It is addition on a clock with 2 hours.

Perfect, but impractical

If the key is truly random, as long as the message, and never reused, the scramble reveals nothing at all. Claude Shannon proved it in 1949. This is the .

Spies once carried pads of random digits on paper and destroyed each page after one use, hence the name. Use a page twice and an eavesdropper can XOR the two messages together, which cancels the key out.

One-time pad on Wikipedia

The catch: every secret byte needs its own byte of key, handed over in secret beforehand. To send a gigabyte, you first have to share a gigabyte.

Stretching a short key

Modern ciphers stretch a short key instead. The standard is . It cuts the message into blocks of 128 bits and puts each block through rounds of mixing: 10 rounds with a 128-bit key. Each round swaps chunks using a fixed table, moves bits around, and stirs in part of the key.

The Advanced Encryption Standard, designed by Belgian cryptographers Joan Daemen and Vincent Rijmen and adopted by the US standards agency NIST in 2001. Keys of 128, 192, or 256 bits get 10, 12, or 14 rounds. Many secure web connections use it.

AES on Wikipedia

The goal: change one input bit and about half the output bits flip, with no pattern to follow.

A one-way fingerprint

Mix hard enough with no key at all, and keep a short result. That is a : a fingerprint of the text. The same text always gives the same fingerprint. Change one letter and it looks brand new. And nobody knows how to run it backward.

A hash function turns input of any length into a fixed-size output. SHA-256, published by NIST in 2001, gives 256 bits, written here as 64 hexadecimal digits (0 to 9, then A to F, each worth 4 bits).
