Secret codes

Shift every letter

Each letter on the outer ring becomes the letter just inside it. Julius Caesar wrote private letters this way with a shift of 3, says the Roman historian Suetonius.

The shift is the . Anyone who knows it can turn the ring back and read the message.

A key is the secret setting that locks and unlocks a code. The method itself can be public. Only the key has to stay hidden.

Crack it: count the letters

Some letters are far more common than others. About one English letter in eight is E. A shift turns every E into the same new letter, so the most common letter in the scramble is probably E in disguise.

Count how often each symbol appears, then match the counts to the language. It breaks any code that always swaps a letter for the same symbol. The scholar al-Kindi wrote it down in the 800s. His manuscript is the earliest known written explanation of code breaking.

What a good code needs

Shuffle the alphabet into any order instead of shifting it. Now there are keys, about 4 × 1026. Nobody can try them all. Yet the bar chart still cracks it, because every E still turns into the same letter.

26! ("26 factorial") is 26 × 25 × 24 × … × 1. It counts the ways to put 26 letters in order: 26 choices for what A becomes, 25 left for B, and so on.

Factorial on Wikipedia

So a good code needs two things. It needs so many keys that trying them all is hopeless. And it must hide patterns, so the scramble looks like noise.
